fix(diag): read the ring out of the app's store again

The reader reported "no record found" for a store that did hold one. Two causes,
both fixed:

- the value is UTF-16LE and does not start at the byte after the key (leveldb
  puts a record header between them), and it can sit next to record boundaries,
  so slicing to the last bracket in a window missed it. The array start is now
  found as the byte pair 5B 00 and walked to its matching bracket.
- Node 24.9 on Windows corrupts its heap after a few dozen Buffer#toString calls
  over multi-KB ranges (STATUS_HEAP_CORRUPTION, exit -1073740940), which is what
  the old crash was. Decoding is done by hand now, and the script says why, so
  the next person does not re-learn it.

An empty store is reported as what it is: nothing was written at all, which means
the client bundle never ran - and the message says where to check that the
plugin is installed in the profile the app boots.
